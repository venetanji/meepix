# MeePix sprint 001 implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Execute the issue's file-disjoint workstreams; do not stop for another plan approval.

**Goal:** Ship the first editable, persistent animation document and explicit Easel candidate workflow.

**Architecture:** Rust core owns all artwork; UI consumes typed snapshots. Independent core and HTTP crates allow headless verification, with thin Tauri adapters.

**Tech Stack:** Rust, Tauri 2, React 19, TypeScript, Vite.

**Spec:** `docs/codex-sprint-001.md`, `docs/sprint-001-contracts.md`.

## Global Constraints

- Rust is authoritative; no second mutable JS document.
- AI is optional; generated candidates require explicit acceptance.
- Credentials remain native and are never logged, rendered or committed.
- Keep existing Arch native, AppImage, Windows and macOS CI.
- Terra workers at high reasoning, maximum three concurrent agents including coordinator.
- Work on feature branch, draft PR only; no merge, deploy or release.

## Review Focus

- Stale revisions or new documents must reject candidate application.
- Corrupt ZIP/PNG or resource amplification must fail before mutation/allocation.
- Pointer edges, fast drags and zoom must map deterministically to native pixels.
- Network failures must never repeat a generation POST or leak auth via redirects.
- Partial saves and rejected candidates must preserve existing artwork.
